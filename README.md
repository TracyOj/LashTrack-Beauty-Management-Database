# 💅 LashTrack: A Beauty Management Database

> **A relational database solution designed to professionalise appointment scheduling and inventory management for beauty technicians.**

## 📖 Background
> Many independent beauty technicians rely on Instagram DMs for bookings, leading to double-booked appointments, lost revenue, and inventory shortages. **LashTrack** was developed (as part of a Code First Girls project) to replace this manual chaos with a structured data solution.
